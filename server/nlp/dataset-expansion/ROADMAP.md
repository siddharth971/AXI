## 🎯 Quality Gates

### Per-Batch Requirements

- [ ] Zero exact duplicates
- [ ] <15% near-duplicate (>0.85 cosine similarity)
- [ ] All required annotation fields populated
- [ ] Schema validation passed
- [ ] Manual spot-check (5% of batch)

### Monthly Quality Reviews

- [ ] Intent orthogonality analysis
- [ ] Domain coverage assessment
- [ ] Cognitive/emotional distribution check
- [ ] Linguistic diversity audit
- [ ] Bias detection scan

### Quarterly Audits

- [ ] Full dataset deduplication
- [ ] Intent consolidation review
- [ ] Vocabulary novelty assessment
- [ ] Training performance validation
- [ ] External linguistic review

## 👥 Simulated Annotator Profiles

To maintain diversity, samples are generated imagining these expert personas:

1. **Linguistic Expert** - Focus on grammatical variations, register shifts
2. **Domain Specialist** - Deep technical terminology, jargon accuracy
3. **Psychologist** - Emotional markers, cognitive states
4. **Conversation Designer** - Dialog flow, repair strategies
5. **QA Auditor** - Edge cases, adversarial examples
6. **Cultural Consultant** - Regional expressions, code-mixing
7. **Accessibility Expert** - Clear communication, simplification
8. **Security Analyst** - Safety-critical commands, risk assessment
